Package reference

Public API

These names match the ESM runtime and declaration output. There is no browser global, and importing the package does not initialize the document.

Creation and initialization

ExportPurpose
new A11yRepeatableFieldset(root, options?)Creates or reuses the active instance for one root and initializes it transactionally.
createRepeatableFieldset(root, options?)Factory equivalent for one root.
initRepeatableFieldsetAll(scope, options?)Explicitly initializes matching roots within a document or element scope.
init()Idempotently returns the active instance; a destroyed instance cannot be revived.

Instance methods

MethodResult
add({ focus? })Adds one template item or returns a frozen failure result. API focus defaults to false.
remove(target, { focus? })Removes by snapshot, fieldset, or stable key. Focus inside a removed item is always recovered.
move(target, direction)Moves the same owned fieldset one adjacent position up or down while preserving stable keys, names, IDs, values, and eligible focus.
getItems()Returns a new frozen array of frozen item snapshots.
getCount()Returns the active item count, or zero after destroy.
canAdd() / canRemove()Report current command availability using the same minimum/maximum state as native buttons.
destroy()Idempotently removes behavior and plugin-owned resources while retaining current fieldsets, identities, positions, and values.

Operation results

Normal boundaries are discriminated results rather than exceptions.

  • Add failures: inactive, maximum, invalid-key, duplicate-key, invalid-template, or addon-error.
  • Remove failures: inactive, minimum, unowned-item, or addon-error.
  • Move failures: inactive, unowned-item, typed boundary at start/end, or rollback-safe move-error.
  • Successful results contain a readonly item snapshot with element, stable key, zero-based index, and one-based position.

Control Remove requests

RepeatableFieldsetAddonContext.onRemoveRequest(handler) registers at most one component-level owner for Remove-button activation. The handler receives a frozen RepeatableFieldsetRemoveRequest with structural item metadata, the original button, and a single-use request.remove() command.

The approved command rechecks ownership and minimum state while preserving source: "control" and the original trigger. Public instance.remove() is already approved, remains immediate, and bypasses this route. No cancelable or additional lifecycle event is created.

Initialization errors

RepeatableFieldsetError exposes a typed code, safe root and offending-element context, and an optional cause. Codes cover invalid roots/options, missing or multiple owned elements, invalid items/templates/focus/status, key and ID failures, and unresolved template tokens.

Initialization is transactional: a thrown error must not leave listeners, generated UI, changed control state, addon registration, or an active instance entry behind.

Package exports

  • . — readable ESM runtime and declarations.
  • ./min — minified ESM runtime with the same declarations.
  • ./docs — structured, side-effect-free documentation metadata.
  • ./addons/validation-bridge — dependency-free, opt-in item registration and cleanup adapter.
  • ./addons/legend-sync — dependency-free, opt-in committed legend suffix synchronization.
  • ./addons/remove-guard — dependency-free control-request policy and asynchronous confirmation routing.
  • ./addons/accessible-reorder — dependency-free native adjacent Move controls delegating to public move().
  • ./addons/duplicate-item — dependency-free native Duplicate controls with explicit supported-control copy slots delegating to public duplicate().
  • ./addons/undo-remove — dependency-free short-lived Undo UI and explicit safe-state retention delegating exact-key trusted-template restoration to core.
  • ./addons/form-memory-bridge — dependency-free two-phase structural draft adapter and initializer for application-owned form persistence.
  • ./styles.css — optional behavior-independent component CSS.
  • ./package.json — package metadata.

The main entry exports generic addon, request-routing, removal-preparation/restoration, Move, and Duplicate types but does not re-export Validation Bridge, Legend Sync, Remove Guard, Accessible Reorder, Duplicate Item, Undo Remove, or Form Memory Bridge implementations. See addons and integrations for their isolation, privacy, and lifecycle contracts.
