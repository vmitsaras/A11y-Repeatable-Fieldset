Opt-in addon demo

Undo the latest removal without retaining its fieldset

Remove either saved contact, then use the temporary Undo button. Core recreates the item from the trusted template with its reserved key; the addon restores only deliberately marked current state.

Temporary retention: Name, email, and Updates are retained in memory for 30 seconds. Expiry pauses while the Undo button has focus. Passwords, hidden server IDs, validation state, and files are not retained. A restored file input is empty.

Boundaries demonstrated here

  • The removed fieldset itself is discarded; restoration uses trusted template DOM.
  • The reserved key restores stable tokenized names, IDs, labels, and references.
  • Unmarked hidden IDs and passwords return to template defaults rather than old values.
  • File values are never read or assigned and restored file controls are empty.
  • One polite core message announces removal and one announces successful restoration.
