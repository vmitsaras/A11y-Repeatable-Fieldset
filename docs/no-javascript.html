Accessibility notes

  • Both initial items use native fieldsets, legends, labels, and named controls before any script runs.
  • Templates are inert and do not participate in focus order or form submission.
  • Enhancement-only buttons are authored with hidden and become available only after validation succeeds.
  • A no-JavaScript workflow that must change structure needs a separate server action outside this plugin.
  • No runtime behavior or optional CSS is required for the existing controls to submit normally.

Developer notes

Importing the module does not auto-initialize either root. The page calls createRepeatableFieldset only for #enhanced-example, proving initialization remains an explicit application decision.
