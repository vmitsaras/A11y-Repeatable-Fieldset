Public lifecycle developer lab

Inspect completed structural events without exposing form values

The inspector subscribes to the seven exported EVENTS values before initialization and renders a bounded log containing structural metadata only.

Scenario

An integrator wants to understand when initialization, addition, duplication, removal, restoration, adjacent movement, and teardown observations occur. The logger must not become a second live region, retain detached fieldsets, or treat events as cancelable commands.

Inspector boundary

This inspector is ordinary, demo-only document content. It is not an addon, is not exported by the package, and is not required for runtime behavior. The log keeps only the newest 20 entries.

Try it

  • Read the first log entry: one init event reports the server-rendered item without an item-added event.
  • Use the component buttons to add and remove an address; observe source: "control".
  • Use Call add(); observe source: "api" when it succeeds and no success event when the maximum blocks it.
  • Use Call duplicate(); observe new and source structural identity without any form value in the payload.
  • Use Call move() after adding an address; observe stable identity with prior and current positions. A one-item boundary emits no success event.
  • Use the Undo Remove demo to trigger item-restored; this inspector still subscribes to its exported constant and safely formats its structural detail.
  • Choose Destroy instance; the final event is logged and all enhancement controls return to their authored hidden state.

Interactive component

Structural event log

This bounded list is ordinary document content, not a live region. New entries do not move focus; review it when you choose.

    Accessibility notes

    • The component’s own polite status region remains the only live region for Add, Remove, Duplicate, Restore, and Move operations.
    • The inspector does not steal focus or announce every diagnostic update.
    • Form values, server errors, private registries, and addon state are excluded from rendered payloads.
    • Removed-item payloads are converted immediately to primitives; the logger does not retain detached fieldsets.
    • The Destroy event is final for this instance; delayed work must not append later entries.

    Developer notes

    event-inspector.js imports EVENTS and createRepeatableFieldset from the copied ESM asset. It subscribes using exact exported constants, builds log entries with DOM methods and textContent, caps retained entries, and never imports private source.
