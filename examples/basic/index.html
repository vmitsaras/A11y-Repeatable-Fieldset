Accessibility notes

  • Each contact is a native fieldset with a non-empty legend, and the Name input has a visible label.
  • Add and Remove are native buttons; the template remains inert until the plugin creates a new item.
  • Completed structural changes use one polite status region.
  • Automated checks do not replace manual testing of announcements, focus scrolling, zoom and reflow, forced colors, or autofill in the target environments.
